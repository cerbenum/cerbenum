Client architecture
Three layers

One trust boundaryper layer.

The interface holds no secrets. The system service holds no protocol logic. The core is the only layer that touches key material.

Interface

Unprivileged. Holds no secrets and no protocol logic.

HTTPS · TLS

System

FFI · C ABI
L3

Protocol

What it does

End-to-end encryption

Modern primitives, standards-based integration.

Multiplexed transport

TCP, TLS, WebSocket and QUIC behind one session layer.

Smart routing

Automatic server selection with failover.

Kill switch

Traffic stops the moment the tunnel drops.

Zero-knowledge keys

Generated on the device and never sent anywhere.

Profile links

Connections provisioned via veyna:// profiles.

Connection modes

  • Smart

    Automatic proxy with LAN bypass.

  • System proxy

    Routes through the system proxy configuration.

  • TUN

    Full-device tunnel via a virtual adapter.
